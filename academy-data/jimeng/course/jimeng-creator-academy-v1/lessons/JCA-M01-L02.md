**Scope**：Jimeng Web 2026-10-04 观察到的未登录创作首页与最小进入路径；客户端范围限 Web 观察与 iOS 版本历史两条来源。

**Learner Outcomes**：识别「创作」区域与「生成」「画布」入口；解释未登录时「对话」「画布」显示「请先登录」并指出「登录」入口；区分历史 App 版本记录与当前 Web 观察属不同客户端范围；解释最小进入路径。

## Opening

上一课建立了「谁会说什么」的分层判断。这一课把它用在具体地方：你在哪里开始创作、需要什么条件、以及不同客户端看到的东西为什么不能互相证明。

## Teaching Points

- **P01（K-0054）** 2026-10-04 的 Web 未登录创作首页有三样东西：名为「创作」的导航区域；主创作区的「生成」与「画布」两个入口标签；显示「你好，今天想要创作什么？」的创作输入区。｜ *scope note*：来自单次未登录观察，未标注客户端版本；不证明名称与入口在其他客户端、账号或时点一致。
- **P02（K-0055, K-0056）** 未登录时「对话」「画布」显示「请先登录」，页面存在「登录」入口。最小路径：打开官方 Web → 进入「创作」区域 → 若要用「对话」或「画布」，页面提示需先登录 → 通过「登录」入口完成准入 → 回到创作首页 → 识别「生成」「画布」入口 → 在主创作输入区开始创作。该提示**不等于**协议要求的真实身份信息认证。｜ *scope note*：不说明登录方式、账号类型、地区差异或权限条件；登录后的按钮路径未在截图显示，未记录为证据。
- **P03（K-0044, K-0045, K-0029）** App Store「即梦」iOS 版本历史中有 2.3.0 条目，页面显示日期为「7月27日」（**未显示年份，不推断**），更新说明记载「上线Seedance2.0 fast模型，全新多模态创作体验」。它属 **iOS 历史版本记录**，与 Web 未登录观察是不同客户端、不同时点、不同性质的来源，不能互相证明；协议层真实身份认证前提（完成认证后才可使用生成、制作、发布功能）与「请先登录」也是两个不同要求，不可互相替代。｜ *scope note*：只复述页面文字；不推断 fast 与普通版关系、首次上线时间、账号/地区/设备端开放范围，也不把「全新多模态创作体验」转成质量结论。

## 练习与检查

- **Guided**：`PEDAGOGICAL_EXAMPLE` 在页面上依次指出创作区域、两个入口、两处「请先登录」、登录入口；口述最小路径；回答「这条提示能否证明未登录时任何功能都不能用」。
- **Independent**：不看清单写出最小路径；从三类来源中挑两个，各写一句「能说明什么、不能说明什么」。
- **Completion**：能指对位置、说出最小路径，并说明「请先登录」≠ 真实身份认证、Web 观察与 iOS 版本记录不能互证。

## 边界与易混点

- 把「请先登录」当成协议的真实身份信息认证。
- 用 iOS 版本记录证明 Web 行为，或反之。
- 为版本 2.3.0 推断年份。
- 把「对话/画布未开放」扩大成「未登录时什么都不能用」。
- 把「创作/生成/画布」等名称当作永久不变。

## 小结与限制

**小结**：把分层判断落到起点画面——认识创作区域、两个入口与登录准入提示，记住最小路径，并学会不把三种来源互相证明。

**Limitations**：只覆盖 2026-10-04 单次未登录 Web 观察与 App Store 版本历史条目；不含登录后页面结构、iOS/Android 界面路径、会员/积分/价格/权限条件；不推断版本年份；本课不含创作操作步骤。
