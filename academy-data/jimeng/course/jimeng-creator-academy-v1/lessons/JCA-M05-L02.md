**Scope**：2026-10-04 观察到的 Jimeng Web 视频生成 / Seedance 2.5 / 全能参考界面中的加入路径、总量提示与引用方式。

**Learner Outcomes**：解释「全能参考」下「参考内容」的加入路径；解释界面总量提示并说明它不是分类型上限；解释图文音视频多元素组合与 @ 引用方式。

## Opening

上一课知道了有哪几类参考方式，这一课走到界面上：入口在哪、能加多少、以及 @ 引用怎么写。这里有一个数字最容易被讲错——「50」。

## Teaching Points

- **P01（K-0057, K-0011）** 已登录界面中「全能参考」的加入路径：进入「生成」→ 选择「视频生成」→ 选择「即梦 Seedance 2.5」→ 选择「全能参考」→ 在主输入区的「参考内容」处上传参考素材，**或在输入中用 @ 引用参考内容**。这与产品页把「上传素材」与「输入提示词」并列为同一步骤一致。｜ *scope note*：不含系统文件选择器步骤（截图未显示）、素材格式/大小/时长/分项数量条件、积分会员价格权限；不表示所有账号、地区或客户端均可用；来自单次观察。
- **P02（K-0059）** 「参考内容」处显示**「上传最多50个参考素材」**。两条必须守住的边界：它是**当前产品界面**的总量提示，**不是**模型层永久技术上限；**不得**改写为「图片最多50张」「视频最多50段」「音频最多50条」等分项上限。证据也未说明超出后的行为、计数方式，以及三类素材是否共用同一配额。｜ *scope note*：该数值只属当前界面与时点；不表示其它账号、地区、客户端或后续版本保持同一数值。
- **P03（K-0058, K-0014）** 该界面说明写明可**输入文字或 @ 参考内容**，自由组合**图、文、音、视频**多元素；示例给出 @图片1、@视频1 与 @音频1，其中 @音频1 对应「音色参考」，@视频1 在被 @图片1 模仿其动作的示例中作动作参考对象。**关键边界**：示例中的 @音频1 与「音色参考」**不证明存在独立的音频上传入口**——该路径**未单独验证**，**不等于「不支持」**。｜ *scope note*：不表示三类素材拥有相同格式/大小/时长条件；产品层音画协同声明不等于模型技术细节。

## 练习与检查

- **Guided**：`PEDAGOGICAL_EXAMPLE` 在界面上找到「参考内容」入口并按路径完成一次加入；写出一次 @ 引用；回答「最多50个」指的是什么范围。
- **Independent**：写出加入路径，并做两处纠错：改写「图片最多50张」、改写「这个界面不支持上传音频」，各说明理由。
- **Completion**：能说出加入路径、解释 50 是界面总量提示而非分项/模型上限，并正确说明独立音频上传入口处于「未单独验证」。

## 边界与易混点

- 把「最多50个参考素材」写成图片/视频/音频各自的上限。
- 把界面显示的 50 当成 Seedance 2.5 模型层的永久技术上限。
- 把 @音频1 与「音色参考」当成独立音频上传入口已被验证。
- 把「未单独验证」读成「不支持」。
- 假定该路径在所有账号、地区、客户端与版本保持不变。

## 小结与限制

**小结**：走通参考内容加入路径（生成 → 视频生成 → Seedance 2.5 → 全能参考 → 上传或 @ 引用），并守住两条表述纪律：50 是当前界面总量提示；独立音频上传入口为「未单独验证」。

**Limitations**：只覆盖 2026-10-04 单次已登录界面观察与产品页说明；不含文件选择器步骤、素材格式/大小/时长/分项数量条件、积分会员价格权限、超出上限后的行为与计数方式；不证明其它版本或账号界面一致；本课不含完整 UI 导览。
