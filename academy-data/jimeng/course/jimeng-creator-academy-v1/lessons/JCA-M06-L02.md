**Scope**：2026-10-04 观察到的 Jimeng Web / Seedream 5.0 Pro 图片修改任务的提交、复查与交付，以及结果页可见入口的验证状态。

**Learner Outcomes**：输入一次针对已有图片的局部修改要求并提交执行；检查结果并完成下载，或选择重新编辑、再次生成；解释「局部重绘」等只是结果页可见入口，内部步骤尚未验证；解释「其他保持不变」是修改要求，不是产品保证。

## Opening

上一课理解了局部编辑的能力与边界。这一课动手：对一张已有图片提出一次修改要求，提交、复查、交付。这里有两句话必须说准——「其他保持不变」，以及那些看得到但没验证过的入口。

## Teaching Points

- **P01（K-0060）** 已登录界面中一次修改任务的顺序：**加载已有图片 → 在输入框写明修改要求 → 经输入框右侧执行入口提交 → 由 Seedream 5.0 Pro 生成修改后的结果 → 在结果页查看，可重新编辑或再次生成 → 下载结果**。该次任务的要求是「只把人物上衣改成蓝色，其他保持不变」。｜ *scope note*：限 Jimeng Web、限该截图时点、限 Seedream 5.0 Pro 图片链路；不含文件选择器步骤与素材规格。
- **P02（K-0060）** 「**其他保持不变**」是**用户提出的修改目标**，不是产品保证——不得据此写成「只会修改目标区域、其它一定不变」。证据也不说明提交后是否必然产生可用结果，以及生成耗时、额度或权限。｜ *scope note*：该要求是用户侧表述；不代表产品行为承诺。
- **P03（K-0061）** 结果页显示修改后的图片预览，并提供**「重新编辑」「再次生成」「下载」**；结果详情页同时可见「去画布编辑」「局部重绘」「智能改图」「细节修复」「扩图」「消除笔」等**入口文字**。关键纪律：这些子工具只被验证为**可见入口**，其内部操作步骤**未被验证**（「未验证」，**不是**「不支持」）。另外，本证据**没有验证** Seedance 2.5 的视频编辑。｜ *scope note*：不写成子工具的完整流程；不保证保真度与保留要素一致性。

## 练习与检查

- **Guided**：`PEDAGOGICAL_EXAMPLE` 对一张已有图片提交一次局部修改要求，完成复查与下载；指出看到的入口文字并说明各自被验证到什么程度。
- **Independent**：写出修改任务的完整顺序，并完成两处改写：把「其他保持不变」、把「局部重绘能这样做」改写成符合证据的表述。
- **Completion**：能按顺序完成一次图片修改任务并交付，说明「其他保持不变」是用户目标，并说明结果页子工具入口处于「未验证」状态。

## 边界与易混点

- 把「其他保持不变」当成产品保证。
- 把「局部重绘」「去画布编辑」等入口文字当作已验证的完整流程。
- 把「未验证」读成「不支持」。
- 用本课证据推断 Seedance 2.5 的视频编辑能力。
- 假定提交后必然产生可用结果，或假定耗时、额度与权限。

## 小结与限制

**小结**：完成图片修改任务的执行与交付（加载 → 写明要求 → 提交 → 生成 → 复查 → 下载），并守住两句表述：「其他保持不变」是用户目标；结果页子工具只是可见入口。

**Limitations**：scope 限 Jimeng Web、限 2026-10-04 截图时点、限 Seedream 5.0 Pro 图片链路；本证据未验证 Seedance 2.5 视频编辑；不含文件选择器步骤、素材规格、提交后必然性与耗时/额度/权限信息；子工具内部步骤未验证；不表示所有账号/地区/版本界面一致。
