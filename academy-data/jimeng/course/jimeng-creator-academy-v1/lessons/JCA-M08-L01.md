**Scope**：Jimeng Web 2026-10-04 观察到的创作入口与准入范围，以及本课要求的任务目标设定。

**Learner Outcomes**：识别创作入口并按需要完成登录准入；说明本次创作的目标与可交付结果。

## Opening

综合模块开始。它与其他模块的区别是：这里不再教新知识，而是把已经学过的串起来用。第一件事是准备——进得去、说清要做什么。

## Teaching Points

- **P01（K-0054）** 认出起点画面：未登录创作首页上有「创作」导航区域、「生成」与「画布」两个入口标签，以及显示「你好，今天想要创作什么？」的主创作输入区。这一步不需要新技能，只需在真实界面上**指对位置**。｜ *scope note*：来自单次未登录观察；不证明名称与入口在其他客户端、账号或时点一致。
- **P02（K-0055, K-0056）** 未登录时「对话」与「画布」显示「请先登录」，页面存在「登录」入口。最小路径：打开官方 Web → 进入「创作」区域 → 若要用「对话」或「画布」，页面提示需先登录 → 通过「登录」入口完成准入 → 回到创作首页 → 识别「生成」「画布」入口 → 在主创作输入区开始创作。该提示**不等于**协议要求的真实身份信息认证。｜ *scope note*：登录后的按钮路径未在截图显示，未记录为证据；不含 iOS/Android 路径与权限条件。
- **P03（K-0056）** 准备阶段的第二个动作是**把目标写下来**：用一句话说明这次要做什么、要拿到什么可交付结果。这不是产品功能，而是课程的方法要求——先有目标，后面的提示词与结果判断才有依据。｜ *scope note*：目标设定属课程方法要求，不是产品行为或界面能力。

## 练习与检查

- **Guided**：`PEDAGOGICAL_EXAMPLE` 进入创作区域、识别两个入口、按需要完成登录准入、写下一句创作目标与预期交付物，并复述路径。
- **Independent**：不看路径说明完成进入并写出目标与可交付结果；回答如何纠正「未登录时什么都不能用」这一说法。
- **Completion**：能进入创作区域、按需要完成登录准入，并写出本次创作目标与预期可交付结果。

## 边界与易混点

- 把「请先登录」当成协议要求的真实身份信息认证。
- 把登录后的具体按钮路径当成已验证步骤。
- 跳过目标设定直接操作，导致后面无法判断结果是否可用。
- 把「对话/画布未开放」扩大成「未登录时什么都不能用」。

## 小结与限制

**小结**：完成综合创作前的准备——认出创作区域与两个入口、完成登录准入、记住最小路径、写下一句可交付的创作目标；并确认「请先登录」≠ 真实身份认证要求。

**Limitations**：只覆盖 2026-10-04 单次未登录 Web 观察；不含登录后页面结构、iOS/Android 路径、会员/积分/价格/权限条件；不推断名称永久不变；本课不含创作操作步骤。
