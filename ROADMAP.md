# Roadmap

## Frozen baseline — V1 / Phase 1

- Evidence/source registry
- Knowledge normalization and graph contracts
- 8-module / 24-lesson Jimeng Creator Academy V1
- 23 concrete assessments
- 24 mastery units
- Course-level evaluation
- Native project Skill routing

## Near-term community work

- More reproducible source-refresh workflow
- Version-drift checks for current Jimeng Web behavior
- English localization of learner-facing lessons
- Contributor-friendly regression runner
- More negative fixtures for cross-layer leakage
- Documentation/examples for adapting the Academy architecture to other topics

## Future phases (not part of V1)

- Persistent Student State
- Tutor Engine
- Adaptive learning paths
- Multi-platform course variants
- Additional creator tools / domains

Future work should build on the frozen V1 contracts rather than silently changing their meaning.
