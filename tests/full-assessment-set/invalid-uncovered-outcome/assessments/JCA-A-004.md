## scope

该官方产品页所述图片生成流程与 2026-10-04 观察到的 Jimeng Web 图片生成界面；不含「画布」完整能力、调整功能参数与结果质量评价。

## task

不看步骤清单，独立完成一次图片创作并交付：①写出一句本次创作目标；②写出一条以对象为起点、由短句组成的图片提示词；③完成触发生成并查看结果；④完成一次下载交付。交付时附三段说明：你的创作目标；你的提示词为什么以那个对象为起点；如果你要调整一次，你会选择修复、展开还是删除，依据是什么。

## expected_evidence

①书面创作目标；②写出的提示词（可见对象起点与短句组织）；③下载产物；④三段说明文本。
