## Task

## Expected Evidence

①一句说明参考生视频以上传参考视频为特征、用参考视频传达需遵循的动态细节；②两种基础输入方式（文字提示词、图片视觉参考）；③多模态组合的四类素材（脚本、视频、音频、风格素材）。
