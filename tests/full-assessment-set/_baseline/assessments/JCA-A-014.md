**Target Outcomes**

## Task

在已证实的界面上按顺序写出加入参考内容的路径，并完成一次参考素材加入或一次 @ 引用。然后回答两个问题：「上传最多50个参考素材」指的是什么范围？当前界面支持的 @ 引用包含哪几类？

## Expected Evidence

①路径（进入生成 → 选择视频生成 → 选择即梦 Seedance 2.5 → 选择全能参考 → 在参考内容处上传，或在输入中用 @ 引用）；②一次实际加入或 @ 引用的记录；③回答 50 是当前界面的总量提示、不是分类型上限也不是模型层上限；④@引用包含图片、视频、音频三类。
