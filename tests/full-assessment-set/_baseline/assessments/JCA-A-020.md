**Purpose**：测量 JCA-M07-L04 的两条 outcome：学生要说明平台处理条款的组引用范围与处理上下文，并把真实身份认证前提对应到实际生成动作。

**Target Outcomes**
- 解释平台处理条款所引用的规则集合范围与处理上下文
- 解释真实身份认证前提限定基础生成工作流中的实际生成动作

**Knowledge Refs**：JIM-K-0029, JIM-K-0035, JIM-K-0009, JIM-K-0010, JIM-K-0046

**Scope**：平台规则限 P14 第 4.8 节与第 4.3 节；准入结构限 P14 §4.3 与 P10 第三步的对照范围，即真实身份认证前提对视频生成流程中实际生成动作的约束。

## Task

对一次计划中的视频生成，依次回答三个问题：①该创作涉及哪一条准入前提？②该前提约束流程中的哪一步、不约束哪一步？③如果行为被认定为违反或可能违反「上述约定」，处理条款覆盖的范围是什么？然后改写两句话并说明理由：把「违反规则就会被封号」改写成符合证据的表述。

## Expected Evidence

①指出涉及真实身份信息认证这一准入前提；②指出它约束的是第三步中的实际生成动作，不约束进入工具与查看下载；③说明处理条款引用的是「上述约定」这一规则集合、描述的是处理上下文；④两句改写，把后果表述为处理上下文而非必然处罚。
