**Scope**：该官方产品页所述的图片生成三步流程与起点，以及 2026-10-04 观察到的 Jimeng Web 图片生成界面中的提示输入与触发生成环节；不含结果导出环节（见下一课）。

## Opening

上一课你在 Jimeng Web 找到了创作入口并了解了登录准入。这一课进入实际操作的第一段：看清这条图片生成流程由哪三步组成、从哪里开始，然后完成你的第一次提示输入与触发生成。本课只走到"触发"为止，结果怎么看、怎么下载属于下一课。

## Teaching Points

### M02-L01-P01（JIM-K-0051）

该官方产品页把从文本生成图像说明为三个步骤：第一步"输入提示引导AI"，第二步"生成您的图像"，第三步"增强、定制和导出"。该页同时写明起点是登录后进入"生成图像"下的"文本/图像到图像生成"部分。也就是说，这条流程不是从"直接写提示词"开始，而是从进入正确的位置开始。

*Scope note*：只描述该页写明的步骤名称与起点；不代表所有客户端、账号或版本的界面结构一致，也不表示该页之后还有未写明的官方步骤。

### M02-L01-P02（JIM-K-0052）

第二步的做法是：在聊天框中输入文本提示，然后点击"生成"按钮触发。该页另外给出两点表述需要分开看：一是"为了获得更好的视觉效果，建议输入3840 x 2160或4000 x 3000等高像素"——这是**建议**，不是必须满足的输入规格；二是"即梦AI将在几分钟内生成4张图片"——这是该页对结果的描述，不是稳定耗时承诺，也不是固定产出数量。

*Scope note*：建议性像素值不作为输入规格；生成张数与耗时表述不构成保证或 SLA。本课不涉及提示词的具体写法（属 JCA-M04）。

## Guided Practice

在 2026-10-04 已验证的 Jimeng Web 图片生成界面中，按顺序完成：登录 → 进入"生成图像"下的"文本/图像到图像生成" → 在聊天框输入一句描述性文本提示 → 点击"生成"。完成后对照三步流程说出自己刚刚完成了哪一步、下一步是什么。

## Independent Practice

不看步骤清单，先自己写出这条流程的三步顺序与起点，再完成一次提示输入与触发生成；最后回答两个问题：你这次输入是否使用了页面建议的高像素值？如果没用，是否影响你完成这一步？

## Completion Check

学生能在该界面完成一次提示输入与触发生成，并按顺序说出三步流程及其起点。

## Boundaries and Misconceptions

- 把"建议输入3840 x 2160或4000 x 3000等高像素"当成强制规格。它是建议，不是要求。
- 把"几分钟内生成4张图片"当成稳定耗时或固定产出。它是页面描述，不是承诺。
- 把该产品页所述流程当成所有客户端、账号或版本的通用界面。它只是该页所述内容。
- 把"三步流程"当成提示词写法课：提示词的组织与修订属 JCA-M04，本课只到输入并触发。

## Lesson Summary

本课说明了该官方产品页的图片生成三步流程与起点（登录后进入"生成图像"下的"文本/图像到图像生成"），并完成了第一次文本提示输入与触发生成。你同时确认了两处容易误读的表述：高像素值是建议，几分钟生成 4 张不是承诺。
