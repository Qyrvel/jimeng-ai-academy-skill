# Course, assessment, and mastery

Jimeng Creator Academy V1 contains 8 modules and 24 canonical lessons. The authoritative course package is under `academy-data/jimeng/course/jimeng-creator-academy-v1/`.

Assessment is outcome-based rather than a single global percentage. A numerical score may exist for a concrete assessment, but it cannot erase an unmet required outcome.

Mastery decisions:

- `PASS` — required outcomes are satisfied and hard prerequisites are satisfied.
- `RETRY` — the main gap is execution/evidence completeness rather than a conceptual misconception.
- `REMEDIATION` — a required outcome or boundary concept is not yet demonstrated.
- `BLOCKED` — a real hard prerequisite is not satisfied.

Course-level decisions preserve retry/remediation/blocked routing targets even when a higher-precedence overall status is selected.
