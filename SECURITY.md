# Security Policy

Do not open a public issue for credentials, tokens, private user data, or a vulnerability that could expose user systems.

Before reporting a security issue, confirm it is about this repository's code or workflow rather than the Jimeng service itself. This project is unofficial and cannot fix vulnerabilities in third-party products.

Never commit API keys, cookies, login sessions, private screenshots, or account-specific URLs. The public source layer intentionally excludes login-bound evidence and raw captured third-party materials.
